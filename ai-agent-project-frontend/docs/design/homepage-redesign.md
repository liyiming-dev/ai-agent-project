# 首页设计风格缺陷分析与改进指南

> 范围:`HomePage.vue` + `BasicLayout.vue` + `theme.css`
> 状态:**不改代码**,先对齐方向。配套预览见同目录 `homepage-redesign-preview.html`,可直接在浏览器打开看效果。

---

## 一、为什么现在看起来"AI 味重 / 死板"

把你的直觉拆成 **7 个可定位的视觉信号**,每一条都对应现有 CSS 里的具体决策。

### 1. 蓝紫渐变大标题 —— 2023 年 AI 产品的"制服"

现状:`--gradient-text: linear-gradient(115deg, #0052CC → #0066FF → #7C3AED → #8B5CF6)`,直接糊在 76px 的 `AI 应用生成平台` 上。

问题:
- 蓝→紫渐变 + 粗体巨标题 = ChatGPT / Copilot / 各种套壳站的默认开场,辨识度为 0。
- 渐变文字在中文笔画细节上发灰、边缘模糊,远看像"打了一层塑料膜"。
- 中文字符本身已经很"满",再叠渐变 + `font-weight: 800` + `letter-spacing: -0.03em` 负字距,视觉密度过载。

### 2. 背景是"PPT 光晕" —— 柔光 + 点阵 + 径向渐变三件套

现状:body 背景 `--gradient-atmosphere` = 4 层径向渐变叠线性渐变,再叠一层 `radial-gradient` 点阵。

问题:
- 这套"蓝紫柔光+点阵"是 Midjourney 早期 landing、各类低代码平台、甚至很多简历模板的通用底。
- 柔光太均匀、无方向感,缺少"光从哪来、物体在哪"的空间关系。
- 点阵密度太细 (1px,间距 ~24px 默认),远看像屏幕脏污,不像有设计语言的装饰。

### 3. 卡片是"白底圆角阴影三件套",没有性格

现状:
```
background: #FFFFFF;
border: 1px solid var(--ink-200);
border-radius: 14px;
box-shadow: var(--shadow-card); /* 柔和蓝阴影 */
```

问题:
- 白卡片 + 浅灰描边 + 蓝柔光阴影 = Ant Design / shadcn / Notion 的最大公约数。
- 6 张结构完全一致的卡片 3×2 排布,没有视觉节奏(没有大图、没有强弱、没有留白变化)。
- 封面占位用的是同一张 `logo.png` + 蓝紫渐变底,6 张长得一模一样,列表看起来像"加载中"。
- "查看对话 / 查看作品"两个按钮大小一样、优先级不清。

### 4. Hero 的"发光输入框"是模板感最重的控件

现状:白色圆角 20px 大输入框 + 底下 `prompt-glow` 蓝色径向模糊 + 右下角蓝色圆形渐变发送按钮。

问题:
- 这个组合 = v0.dev / bolt.new / Lovable 的原样复刻。
- 输入框外的"蓝光底座"在白底上没有承载物,显得"凭空发光",不符合任何真实光照逻辑。
- 发送按钮用品牌主渐变 + 大阴影,在一个极简页面上过于"抢镜",把用户注意力从文字上拉走。

### 5. 字体层级只有"粗"和"特粗",缺中间档

现状:Hero 800、Section title 700、卡片名 600、正文 400。**跨度大,但节奏缺 500 这一档**,且全部 Inter 无衬线,没有对比。

问题:
- 页面从头到尾一种字重感,只有大小差别,像 Figma 模板。
- 中文用 PingFang SC 回落,Inter 只影响英文数字;英文标题(STUDIO / Curated)是小尺寸大字距 700,非常典型的"美式 SaaS kicker",在中文站里是外来语感。

### 6. 色彩只有"蓝 + 紫 + 灰",纯度单一

现状:`theme.css` 里 blue 10 级 + purple 6 级 + ink 10 级。**完全没有暖色、没有中性陶土色、没有任何能打破蓝紫的点睛色。**

问题:
- 蓝色是"安全色",所有工具站都用,所以也是"无记忆色"。
- 整站没有一处暖色,视觉温度偏冷,传达不出"创造、生成、手作"的气质,反倒像金融/SaaS 后台。

### 7. 留白是"匀速"的,没有呼吸

现状:section gap 80px、卡片 gap 20px、hero padding 64px、section head margin-bottom 28px。

问题:
- 所有间距都是 8 的倍数,标准但"工程化",没有任何一处刻意的大留白或紧凑对比。
- Hero 底下 suggestion chips → STUDIO 之间 80px 空,但 80px 空白里没有任何视觉过渡(没有分隔、没有引导、没有小装饰),看起来像"没设计完"。

## 二、想要往哪走:三个可选方向(选一)

下面三个方向都能"去 AI 味",各自取舍不同。**建议先选一个做 Hero + 卡片区,再推全站。**

### 方向 A —— **Editorial Minimal(杂志极简)** ⭐ 推荐

参考:Linear、Vercel 官网、Rauno.me、Framer 2024 landing

核心打法:
- **黑白灰为主**,品牌色只出现在**一处**(比如光标、发送按钮图标、或 hover 下划线)。
- **衬线字体做中文大标题**(霞鹜文楷 / 仓耳今楷 / Source Han Serif),或无衬线 + 大字距但**不加渐变**。
- 背景纯白或 `#FAFAF7`(暖白)或 `#0B0B0C`(深墨),**彻底删掉径向光晕和点阵**。
- 卡片无描边、无阴影,**靠留白和字体分层**,hover 时出现下划线或色块。
- 全站只用 1–2 种字重(Regular + Medium),避免 "粗体海"。

适合:想做一个"有审美的工具"的印象,吸引设计师/独立开发者用户。

### 方向 B —— **Warm Tech(暖色科技)**

参考:Anthropic 官网、Vercel Ship、Posthog、Resend

核心打法:
- 主背景换成**温暖米白 `#F7F3ED` / `#FAF5EE`**,打破冷蓝底。
- 品牌蓝保留,但降低饱和度(从 `#0066FF` 降到 `#2B5CE6` 或更柔的 `#3D5AFE`),并引入**一个陶土橙/焦糖色**作为点睛(`#D97757` / `#C2410C`)。
- 保留渐变但**只用在小面积**(按钮、badge),不用在标题。
- 卡片用米白 + 细黑描边(1px `rgba(0,0,0,0.08)`),阴影几乎不可见。
- 装饰用"手绘感线条"或"单色插画"代替径向光。

适合:想做有品牌辨识度、有温度的产品站。Anthropic 就是这个路线。

### 方向 C —— **Brutalist / Swiss(野性瑞士)**

参考:Vercel OSS awards、Read.cv、Are.na、Rauno 部分项目

核心打法:
- 纯黑 + 纯白 + 一个饱和重色(正红 / 芥末黄 / 电光绿)。
- **粗黑描边 2px**,矩形锐角或 4px 小圆角,**禁用大圆角和阴影**。
- 等宽字体 + 无衬线大标题,故意错位/溢出排版。
- 卡片可以直接用黑底白字 / 白底黑字 / 重色底,形成节奏。

适合:想传达"我们和别的 AI 站不一样"的态度,但**会筛用户**,企业向慎用。

## 三、具体改造清单(按方向 A 写,另外两个方向原理同)

### 3.1 Hero 区

| 项 | 现状 | 改为 |
|---|---|---|
| 主标题 | `AI 应用生成平台`,76px 800 蓝紫渐变 | 换成 **双行主副标题**:`用一句话,<br>造一个网站。` 60px Regular/Medium 纯黑,或改用中文衬线字体(思源宋体 / 霞鹜文楷) |
| 副标题 | `一句话轻松创建网站应用` | 删,或改为一行左对齐小字说明(14px ink-500) |
| 对齐 | 居中 | **改左对齐**,整页走一条隐形左纵轴,杂志感立刻上来 |
| 输入框发光 | `prompt-glow` 径向蓝光 | **删除** |
| 输入框描边 | 1px `ink-200` + 蓝阴影 | 1px `ink-300`,无阴影,`focus` 时描边变 `ink-900` |
| 发送按钮 | 蓝紫渐变圆形 + 大阴影 | 44×44 纯黑方形 2px 圆角,或直接用一个"↵ 发送"的文字按钮 |
| 快捷提示 | 居中"Ctrl/⌘ + Enter 发送" | 保留,但用 `text-xs ink-400`,放输入框下方左对齐 |
| Suggestion chips | 胶囊按钮 + hover 变蓝 | 改为行内文字链(前缀 `试试 ›`),逗号分隔,hover 下划线 |

### 3.2 背景

- 删除 `body::before` 的点阵 overlay。
- `--gradient-atmosphere` 简化为单色 `#FAFAF7`(暖白)或 `#FFFFFF`。
- 如果实在想要氛围,**只在 Hero 区**放一层极淡的斜向线条(SVG,0.04 透明度),不要径向光。

### 3.3 分区 Head(STUDIO / Curated)

现状:小字大字距的英文 kicker + 中文大标题 + 右侧渐变横线。

改为三选一:
1. **只留中文标题**,左边加一条 24px 的粗竖线(2px 黑),删掉英文 kicker 和横线。
2. 中文标题 + 右侧显示数量(`我的作品 — 12`),极客感。
3. 英文 kicker 保留但降级为正常字距 Regular 12px ink-500,别再 0.32em 撑开。

### 3.4 作品卡片(最关键)

现状 6 张卡片一致 + 占位图一致 = **整页最"AI 味"的区域**。

改造:
- **打破网格**:首张卡片横跨 2 列(大图),其余 4 张正常。或首行 2 张 + 次行 3 张的节奏。
- **去掉卡片背景和描边**,`.app-card { background: none; border: none; box-shadow: none; }`。靠封面图 + 下方文字的组合成立。
- **封面占位重做**:不要再用 `logo.png` + 蓝紫渐变底。用 **Mono 字母标**(取 appName 首字)黑底白字大字号,或纯色色块循环(6 种预设色,按 id hash 分配),立刻有节奏。
- 封面高度从 `180px` 改为 **`aspect-ratio: 4/3`** 或 `16/10`,图片尺寸不受容器宽度影响。
- 卡片下方只保留 `app-name`(15px Medium)+ 作者名(12px ink-500),hover 时名字下出现 1px 下划线。
- "查看对话 / 查看作品"两个按钮 → **hover 时才显示**,默认态更干净。或者整卡 click = 打开作品,"查看对话" 作为次要文字链挂在右下。

### 3.5 色彩

- 保留品牌蓝,但**只在以下位置出现**:输入框 focus 描边、发送图标、分页当前页、链接 hover。
- 删除所有"蓝色柔光阴影"`rgba(0, 82, 204, 0.x)`,改用中性 `rgba(0,0,0,0.06)`。
- 新增一个**警告/强调色**(可选橘 `#D97757` 或绿 `#059669`),用在"精选"徽章 / 已部署状态等,打破蓝独奏。

### 3.6 字体

- 主标题改用 **衬线中文字体**:免费可选 `Source Han Serif SC` / `LXGW WenKai`(霞鹜文楷),气质完全变。
- 代码/ mono 保留 JetBrains Mono。
- 删除所有 `font-weight: 800`,改为 600 上限。

### 3.7 动效

- 现有 `fadeUp` + 渐次延迟 55ms 本身 OK,但**曲线过于"果冻"**(`ease-out-expo` 末段太缓)。
- 改为 `cubic-bezier(0.22, 1, 0.36, 1)` 或更短的 `0.35s`,不要让页面每次都"飘"进来。
- 卡片 hover 的 `translateY(-7px)` 太多,改为 `-2px` 更克制。
- 删除 `.app-cover-sheen` 的扫光效果 —— 这是最 AI 味的微交互之一。

---

## 四、改造优先级(如果只做 3 件事)

1. **删掉主标题的蓝紫渐变**,换成纯黑或深墨绿衬线字体。 **(影响最大,成本最低)**
2. **重做卡片占位图**:去掉 logo.png + 蓝紫渐变,改为首字母 Mono 色块。
3. **左对齐整个 Hero**,删掉输入框 glow 和按钮大阴影。

做完这三步,"AI 味"应该能下降 60% 以上,再看是否继续推进。
